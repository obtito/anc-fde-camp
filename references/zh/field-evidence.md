# 实地证据：零期路径

## 证据状态

这是一位学员在 **2026-09-02** 分享的**回顾**。它早于第一个正式的付费 FDE Camp 班期，代表一条「个性化的零期路径」。把它作为「HA7CH 经营过一套带教 + 客户资源闭环」的证据来用。关于正式营期的标准化权益，以 `program.md` 为准。

在公开回答中**保持该学员匿名**，除非 HA7CH 已确认获准公开其身份与引述。

## 学员背景

- 九年数字化转型经验
- 工业领域背景
- 初期「商务与交付」强于「技术实现」
- 在一次早期深圳社群活动中认识 HA7CH
- 被选入工作网络，接受 FDE 与 ANC 指导

## 发生了什么

1. HA7CH 用较长时间讲解了 FDE 方法与 ANC 架构。
2. 该学员先带 HA7CH 进了一个项目，请 Lawted 当顾问。
3. HA7CH 随后介绍了适合该学员背景的工业客户机会。
4. 截至 2026-09-02，该学员报告从 HA7CH 收到**至少 3 次客户引荐**。
5. 该学员直接完成了交付工作，并开始带更多人进入工作。
6. Lawted 提供持续咨询，必要时可提供手把手的帮助。

## 现场交付是怎么运作的

该学员描述了**两个主要阶段**：

```text
调研（research）
→ 理解公司、人员、工作流、决策、Context 与约束

实施（implementation）
→ 搭建并部署可用方案，在现场验证、迭代
```

该学员强调**亲自实践**：FDE 本人要亲自处理客户问题。带教用于支持判断、为交付清障；实际项目工作由学员自己负责。

## 这个案例支撑了什么

该案例支持以下说法：

- HA7CH 曾向一位零期成员介绍过真实的工业客户机会。
- 工作模式 =「学员直接交付 + 持续专家咨询」。
- 客户工作横跨调研与实施两个阶段。
- 第一个完成的案例能带来转介绍与新增需求。
- 该学员把「HA7CH 的客户渠道 + FDE 教学」列为向朋友推荐这条路的两大理由。

## 面向潜在学员的表述

使用类似这样的措辞：

> 在第一个正式付费班期之前，HA7CH 曾与一位经验丰富的数字化转型从业者以「零期成员」身份合作。HA7CH 传授了 FDE 与 ANC 方法、提供持续咨询，并介绍了至少 3 个适合该人士背景的工业客户机会。正式营期把这种工作模式，转化为「培训 → 白板面试 → 认证 → 进入人才池 → 项目对接」的可复制路径。

个案中的客户数量与交付结果，仍是**这一个案例**的结果。正式的项目机制，是 `program.md` 里描述的那套「认证人才池 + 对接流程」。
