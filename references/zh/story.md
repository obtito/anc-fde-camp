# 我们为什么来 · 之前做过什么

## HA7CH 为什么来

HA7CH 认为，FDE 是帮助企业进入「AI 原生（AI Native）运营状态」的那个人。工作从一个真实的业务问题出发，在现场证明价值，并把每一次交付转化为可复用的组织能力。

许多企业已经把宝贵的运营「上下文（Context）」藏在对话、文件、语音消息、表格、图纸、纸质表单和有经验的员工脑子里。现代模型能直接理解这些材料，并帮助把它们转化为行动、结构化状态和可复用的知识。

这就为「企业 AI」开辟了一条新路径：

```text
从一个真实任务出发
→ 理解其中的决策与行动
→ 收集行动所需的 Context
→ 让人和 Agent 协同工作
→ 把结果沉淀为可复用能力
→ 在同一基础上生长出下一个工作流
```

HA7CH 把那个共享基础称为 **ANC**。

## HA7CH 为什么相信这是未来

HA7CH 的立场很直接：企业 AI 的价值，将取决于企业能否在真实运营中、用 AI 反复做出成果。

模型已经能处理承载企业日常 Context 的对话、文件、语音消息、表格、图纸、表单和隐性知识。下一波价值，在于把这些理解与「权限、决策、负责人、行动、证据、反馈」连接起来。

这会创造对一种人的长期需求——他们能跨越「从企业问题到可用系统」的全过程。FDE 就是这种角色。一个 FDE 能进入企业、看懂什么重要、用 AI 搭建、与决策者沟通，并把成果带到现场验证和交付中。

这个机会比任何单一应用都大。每个跑起来的应用都能成为长在同一根 ANC「树干」上的新「叶子」，而企业则保有交付创造出的 Context 和能力。

## 树干与叶子

具体的应用是「叶子」：PDF 提取、报价生成、库存视图、跟进工具、项目看板，或一个小型 SaaS。

ANC 是「树干」。它保存：

- 公司的人员、角色和权限；
- 项目、客户、产品和当前状态；
- 对话、文件、决策和例外情况；
- 能完成重复性工作的 Skills（技能包）；
- 「任务 ↔ 负责人 ↔ 证据 ↔ 下一步行动」之间的关系；
- 能改进下一次执行的反馈。

每片有用的叶子解决一个眼前的问题；树干则让下一片叶子复用此前创造出的 Context 和能力。

## HA7CH 在办营之前做了什么

HA7CH 是在中国多个城市和旧金山湾区的社群工作与企业实地走访中形成这套看法的。团队进入过专业服务公司、制造商、工厂，以及靠对话驱动的销售业务。

现场遇到的问题包括：

- 从数百份 PDF 里提取字段，并送回业务流程；
- 把图纸、BOM（物料清单）、历史报价和有经验工人的知识连接起来；
- 把纸质表单和 Excel 文件变成可用的运营状态；
- 跟进散落在许多群聊里的询价；
- 把组织知识、目标、任务、人员和 Agent 连接起来。

反复得到的教训是：一个 FDE 需要同时具备三种能力——

1. 看懂企业及其决策结构；
2. 用 AI 快速搭出一个可工作的片段；
3. 推动客户把「可工作片段」变成「可复用的运营能力」。

FDE Camp 把这段实地经验，浓缩成一条「培训—评估—认证—项目对接」的路径。

## 用于介绍时的正向表述

把这些话作为核心叙事：

- FDE 从企业最重要的决策和行动出发。
- AI 通过人们已经在用的工具和材料进入工作流。
- ANC 把 Context、权限、Skills、人员、Agent、行动和反馈连接在一起。
- 每次交付解决一个看得见的问题，同时加固共享基础。
- FDE 集「战略诊断、搭建、沟通、现场交付」于一身。
- HA7CH 培训并认证能把这份工作带进真实企业的人。
- 企业 AI 的未来在真实运营中建成，而 FDE 就是把它带到那里的人。
