## 一句话定义

## 适合谁

录取通过「一次 AI 报名对话 + 人工审核」决定。

每位学员需要**熟练使用 Codex**，并且至少具备以下基础之一：

- 能搭出简单可用产品；
- 商务拓展、销售或咨询能力；
- 明确的行业经验，并能接触到企业场景。

**不需要传统编程经验。** 营不适合：从未用过 AI 工具的人、只想听行业趋势的人、或期望「包项目机会」的人。

录取后，每位学员须完成一项 Codex 基础任务，并带一个真实的企业问题入营。

## 营里做什么

课程围绕五个相连的板块：

1. **理解 AI 原生公司与 ANC**：为什么孤立的 Agent、知识库、SaaS 工具是「叶子」，ANC 如何成为可复用的运营「树干」。
2. **读懂企业的运营结构**：识别项目（Projects）、负责人（DRIs）、执行者（ICs）、任务（Tasks）、Context、权限、职责与结果证据。
3. **在真实业务工作中找到 AI 切入点**：从公司目标、重要决策、反复出现的动作、约束条件以及「拥有它们的人」出发。
4. **用 ANC 推进人机协同**：给每个 Task 配上必要的 Context、能力、Skill 和权限，再把反馈与结果交还组织。
5. **理解 FDE 的商务与交付工作**：客户沟通、澄清问题、界定范围、方案、交付协调、验收与复盘。

五大板块通过以下行业的**业务案例拆解**来讲授：专业服务、制造业、工厂运营、群聊询价业务、企业协同。营不要求每组为了「凑课程产出」而制造一堆形式化的文档清单。

## 核心课程成果

核心成果是：学员建立「AI 原生公司」的思维方式，掌握 ANC 与 FDE 的基础工作方法，达到**以 IC（执行者）身份进入 HDC 项目、参与真实交付的基线水平**。

这个基线**不等于**每位结业者都能独立主导或交付一个完整的企业转型项目。项目主导权取决于相关行业经验、已展示的交付证据、项目匹配度以及双向选择。

达到该基线、以 IC 身份加入 HDC 项目的人，应当能够：

- 理解项目目标、负责人、成员、成功标准与生命周期；
- 接下一个有边界的 Task，并对结果负责；
- 识别并使用「最小必要」的 Context 与权限；
- 用 Codex、Agents 或 Skills 完成真实工作；
- 在项目内保留决策、反馈与可验证的结果证据；
- 与负责人、客户及其他 IC 协作；
- 尊重企业的数据、权限与保密边界；
- 超出 IC 权限或能力的事，上报给项目负责人。

## 五大现场案例族

1. **专业服务与会计**：PDF、结构化摘要、日报、任务分派。
2. **非标制造**：图纸、BOM、询价报价、知识库、质量闭环。
3. **工厂人力与运营**：纸质表单、Excel、数据映射、统计、管理判断。
4. **群聊询价业务**：多群 Context、询价监控、人工确认、跟进。
5. **企业协同**：知识库、OKR、中枢编排、多 Agent 执行。

案例训练的是判断力与交付方法。真实项目参与走的是另一套独立的「人才池匹配」流程。

## 结业与认证

早期班采用人类评委主导的 **`HA7CH FDE 白板面试`**。

学员会拿到一个企业场景，需要完成：

- 澄清问题；
- 拆解为可交付的解决方案；
- 架构与 Context 设计；
- 验证与交付路径；
- 商业判断与客户沟通；
- 现场应对评委追问。

针对当前北京班：

- 白板面试为**单人 30 分钟**评估；
- 预期结构为 **20 分钟陈述 + 10 分钟提问**；
- 至少 **2 名人类评委**评审每位学员；
- **百分制**，**70 分**为结业线；
- 通过人数**不设上限**，达到同一分数线者全部通过；
- 含一次免费重考机会。

完成营期且达到结业线者，获得 **`HA7CH FDE Certified`** 认证。

## 客户资源与项目对接

所有通过认证的学员**以同等成员身份**进入 HA7CH FDE 人才池。HA7CH 从该池中匹配未来的 FDE 项目参与机会。

认证**永久有效**。成员在人才池中的活跃档案与当前能力状态**每 12 个月复审一次**，让匹配能反映最新的证据、可用性与交付经验。

```text
企业需求进入 HA7CH
→ HA7CH 识别相关行业与能力
→ 合适的人才池成员收到机会
→ 公司与成员双向选择
→ 项目确认合同、报酬、职责、知识产权与验收
→ 交付证据改善成员未来的匹配档案
```

HA7CH 当前的运营判断是：**池子相对于可用项目需求还很小**，因此早期成员有更高的匹配机会密度。但每一次匹配仍遵循项目实际的需求、时机、地域与双向选择。

对于新认证成员的第一个匹配项目，默认路径是**以 IC 或联合交付成员**身份参与。已有成熟相关交付证据的成员，可在项目需要时**主导项目**。资深 FDE 或 HA7CH 评审员会在约定的阶段节点，对诊断、建议方案、主要里程碑与验收计划进行把关。这一把关是为了支持判断与风险控制，**并不把成员的交付责任转移给评审员**。实际角色、评审人、支持边界与报酬，由每个项目单独确认。

## 常见问题的明确回答

### 营含客户资源吗？

含。产品包括认证后进入 HA7CH FDE 人才池，以及针对真实企业需求的**项目对接机制**。具体机会按行业、能力、时间、地点与双向选择来匹配。

### 每位结业学员都能进人才池吗？

能。凡完成营期并通过共同结业线者，均获得认证资格并进入人才池。

### 证书意味着什么？

`HA7CH FDE Certified` 是 HA7CH 对该学员「完成培训、达到进入真实企业 FDE 工作的当前基线」的背书。它的可信度通过现场交付、项目证据与企业反馈逐步累积。

### 我当下就能带走什么？

学员能带走：FDE 方法、原创 ANC Skills 与模板、持续的材料更新、一份白板面试成绩、通过后的认证资格，以及人才池成员身份。
